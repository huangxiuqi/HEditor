## 整表删除之后的光标落点 / 连页增量排版的后缀平移

- **整表删除光标跑位**：整格选区盖满整张表时走 `eraseTablesCoveredByCells`，但 `plan.at`
  仍是 `selection().begin()` —— 那一端在表格**内部**（第一个被选中的格），删完这个流位置
  已经不存在，后面的内容顶上来，光标就落在下一段的段中间（用户读作"往后跑了好几位"）。
  改成 `eraseTablesCoveredByCells(FlowPos* anchor)` 带回最靠前那张表的起点，调用方拿它当
  `plan.at`；起点在所有步骤左边，删完仍有效，也正是"表格原来占住的那一处"。
- **连页增量排版塌回第一页**（大 bug）：`shiftSuffixBlockAxis` 那一趟只认分页算术 ——
  每行判 `s + lh > cy + ch` 就 `++page; s = cy`。连页的块轴是**整篇累加的绝对 y**，
  于是从第二页起的后缀每一行都判成放不下、整条被拽回条带顶部：中间空一块、下面的接不上；
  后缀里带表时表从错误的块轴位置续排，整篇塌回第一页。修法：`bandOf/localOf` 两个闭包把
  页号与页内坐标都按位置现算（与 layout.cpp 的 `slabOfY` / `locY` 同一式子），
  段前分页与翻页两支都加 `!cont` 守卫；`page_count` 取走完之后的条带号。
- **同一处还有一半**：`layout.cpp` 记 `state_at_start` 时用的是循环里的 `page_index`，
  而连页下它一路不增（不翻页），全篇每段都是 0 号条带 —— `ReflowState` 的相等判据因此
  从第二页起恒不等，增量每次都落到"后缀平移"那一路。改成连页按 `slabOfY(anchor_y)` 记。
- **判据**：原生 `[48]` +1（删完光标停在表那一处：段 0 偏移 0）、新 `[91]`（连页：中段回车
  之后后缀只让出一行 23.378906 磅、整篇块轴严格递增、增量 == 整篇重排，再带一张表验"表跟着
  下移一行、页数没塌回一页"）；浏览器 `insert` +1、`edit-longdoc` 新 `[11]`（真实 Enter，
  6 条：段数 +1、audit diff 0、页数不塌、让出一行、块轴递增）。七份 edit 367 → 372 条、
  `insert` 34 → 35，`AGENTS.md` 已同步。
- **反向验证过**：临时把 `shiftSuffixBlockAxis` 的 `cont` 写死成 false 重跑 `[91]`，4 条红
  （后缀让出 169 磅而应为 23.4、带表时表上移 140 磅、两处 audit 非 0）—— 判据不是空转。
- **文档**：`docs/文档模型设计.md` 里"有表格时不做增量排版"已过时（现在是"遇到表就在表头
  截断续排"）；`docs/跑测试.md` 的 `edit-longdoc` 行补上连页那几条。

## 五个新功能：水印 / 双击三击 / 拖拽移动 / 拖列宽行高 / 图片环绕

全链路（模型 → 编译/投影 → 排版 → 引擎 → wasm → 命令表 → 宿主 → 菜单 → 公开 API）已打通，
native 9/9（新增 `features` ctest，71 条断言）、浏览器 111 条（新增 `feature.spec.ts` 5 例）、
`npm run check` 全绿（载荷 23 份 / 239 键、公开面 76 项）。

- **模型**：`SectionSpec::watermark`（只 alpha 表达半透明）、`ImageWrap{None,Square,Behind,
  InFront}` + `ImageSpec::dx_pt/dy_pt`（偏移相对锚点，不是绝对页坐标）；新步骤
  `SetSectionSpec` / `SetImageSpec`（五处 visitor 全补）；记录读写 `"wat"` / `"dx"`。
- **排版**：`LayoutFloat` 把浮动图从行内摘出来，横排改成**逐行断行**（每行先
  prune/place floats，上下型下推、四周型取更宽一侧缩窄行宽）；竖排与表格格里退回行内。
  **有浮动图就整篇重排**（`floats_` 非空 ⇒ `must_full`），投影里含原子的块不复用。
- **水印只重光栅**：`rasterSignature` 混水印摘要 + `setWatermark` 走 `repaint()`；
  逐字形沿倾角排（不整行旋转）、按纸面中心锚（改页边距不跟），字体靠
  `hb_font_get_nominal_glyph` 试。
- **表格**：`tableGridJson` 给宿主栅格，`tableGridLineAt` 判内部格线（容差 6 磅，首尾不算），
  `setTableGridCols` 钉显式列宽、`setTableRowHeight` 落 AtLeast。**列宽和表宽不做归一**：
  曾经加过"偏小时按比例拉满"，把 `edit_and_caret_2` 的跨页摘要打红，已回退。
- **输入层四条硬纪律**（写进 `docs/外部API设计.md` 6.1，都是这轮踩出来的）：
  ① 按下只问**一次**命中 —— `hit` 里一次带回 `drag/dragImage` 与 `gridTable/gridCol/gridRow`；
     拆成三条命令（`dragProbe` + `tableGrid` + `hit`）把按下变成三次往返，拖选拖到一半就断、
     图片把手一磅不动。`dragProbe` 命令已删，改成引擎侧 `dragKindAt(p, side, imageHit)`。
  ② 跟着指针走的监听**必须按下这一拍挂上**（`trackMove`）：快速单击是"按下、抬起"背靠背，
     等命中回来再挂就永远收不到那次抬手 —— 症状是"点控件内部清不掉已有选区"。
  ③ 双击/三击之后**仍要 armDrag(true)**（双击再拖 = 从这儿往外选）；**选区起点那一格不算
     内部**（否则反向拖选再也拖不出来）；整格选区与压到表格的选区都不搬。
  ④ **连击优先于搬运**：只有 `count === 1` 才判搬运，否则第二、三下落在已有选区里会被判成
     搬家，双击选不出词、三击选不出段（现象只是"没反应"）。
- **光栅签名改成 presentInternal 里按当前状态重算**：原来只在 `setConfig` / `setEditMode` /
  `registerImage` 三处刷新，水印改完签名没动 ⇒ `pageBitmapFresh` 判"还新鲜" ⇒ 页面不重光栅，
  `repaintedPages: 0`、墨迹一个像素不变。这是 TRAPS 128"签名是唯一判据"的正解补齐。
- **失败的判据有两处是"口径变了"而不是 bug**，改了判据并写明理由：
  `edit-sweep` 横扫要先断连击（相邻两点差 1px、又在 520ms 内 = 真双击）；
  `insert` 大图那节"拖右边框线"现在会把图**搬走**（不换尺寸），量把手前要重取几何。
- `images()[].layout` 原来是 0..4 的档位数字却声明成名字联合 —— 在 `editor.ts` 里折成
  名字，公开面（`setImageLayout` / `images`）只认名字。

## 第二轮：七个手感问题的根因与修法

- **缩放弹回开头**：`paintFull()` 无条件 `scrollY = 0` + 发 `scrollReset`（换文档与换缩放共用
  一条路）。改成 `paintFull(keepScroll)`：缩放按 `新密度/旧密度` 折算滚动位置、不发归零信号；
  宿主 `keepScrollAcrossZoom(before, after)` 同步折算 `scrollTop`（只折算"页顶边距之下"那段，
  上边距是固定 CSS 值）。
- **图片环绕一串毛病**（位置跳段首 / 文字在图的另一边 / 改回行内旧图还在 / 看不出上下方差别）：
  1) `lb.inline_origin_pt` 写成了 `cur_cx` 而不是本行的 `row_x` —— 四周型让宽之后，光标与
     选区落在没让开的那条边，字却画在让开之后（"选了左边、字在右边"）。
  2) 浮动图横坐标原来是"版心居中 + dx"，改成"内容区左边 + dx"（左对齐才是 Word 默认；
     居中的话两侧各留一条，文字只能走一侧）。
  3) 行内 → 浮动时按当前几何反算 `dx/dy`（`floatOffsetsFor`），图留在原处；浮动之间只换 wrap。
  4) 浮动图几何进页指纹（`floatPieceDigest` + `float_fp_prev/new`，变了整页重画）：它不占行盒，
     行带看不见它 —— 这是"渲染不更新 / 旧图擦不掉"的根因。
  5) 浮动框的纵向区间改记**块轴**（分页 = 页号 x 页高 + 页内；连页 = 绝对 y）：原来按页内坐标
     比较，连页下第二页起全部失效。
- **连页下"预先判页"会打断后缀平移**：`local + block_line_h > cy + ch` 这条提前判只在有浮动图
  时生效（那时本来就整篇重排）；没有浮动图时它会引入平移路径复现不出来的规则，
  `auditLayout` 立刻红（实测 diff 78665）。**教训**：给逐行循环加规则要看"后缀整体平移"
  能不能复现它。
- **拖动时两个光标**：起手收起正文光标（`setCaretPhase(false)` = phase + 一次 present，
  另外用 `caretHidden` 抑制闪烁 tick），松手放回；落点竖条的宽度问引擎要（`dropSpot` 载荷
  带 `w`），写死 2px 比正文光标粗一档。手形只在越过门槛之后才变 `move`。
- **点中图片不能复制/剪切**：`copySelection` 只认文本选区。补上"图片对象选区"分支
  （`rev::toSpec` + `writeFragment`），`deleteSelection` 也先认图片（剪切的后一半）。
- **格线看不出能拖**：`pagesEl` 上一帧一次的 hover 探测（复用 `hit` 的三格），
  给 `col-resize` / `row-resize`；图上给 `move` / 八向 `*-resize`。
- **图片拖动**：`moveImage` 现在同时收落点与位移 —— 行内图吃落点（插进文字流的哪儿只能靠
  命中），浮动图吃位移（抓在图身哪一点都行）。只给位移时，从右边缘起手的落点会落在图自己身上。

## 收尾补记（同一天）

- **落点竖条宽度**：写死 2px 比正文光标粗一档 → `dropSpot` 载荷多给一个 `w`（光标自己的宽），
  宿主按 `ceil(w x 密度) / dpr` 摆，与 `caretRectPx` 同一算式；判据钉住"两者差 ≤ 1px"。
- **图片拖动**：`moveImage` 的 `rel` 只说明"这是一次拖动"，落点与位移**两个都传**（见上一条）。
- **精确性坑（新 TRAPS 级）**：块轴坐标在分页下是 `页号 x 页高 + 页内`，再 `- 页号 x 页高`
  折回来会掉精度（第 190 页上末位差 0.008 磅）。后缀整体平移是按行高逐行累加的，
  两边差一点点就 `auditLayout` 整篇对不上（实测 diff 78665）。**没有浮动图时一律不进块轴
  坐标**（`wrap_floats` 开关），有浮动图时反正整篇重排。

## 浮动图拖动跟手

- `hit.drag` 分两类：2 = 行内图（在流里，仍画落点竖条）；3 = 浮动图（不占流，没有插入点）。
  `dragKindAt` 按 `ImageBox.layout == 0` 判。
- 新命令 `previewImageMove`（wasm `previewImageMoveAt`）：只改 `image_preview_` 的 dx/dy，
  `repaint` 不 `relayout`。绘制、命中、选中框、`images()` 全走 `imagePreviewPos` 取有效位置；
  页指纹里的 `floatPieceDigest` 也用它，否则页被判新鲜、只有第一帧跟手。
- `previewImageMove` 里重算该页 float 摘要 + `markPagesChangedFrom`：图挪了版面没变，
  不这么做页位图不重光栅。
- 松手 `moveImage` 落文档并清预览；取消由 `detach` 发 `clearImagePreview`。
- 判据：`image.spec` 两条（square / behind）钉"拖动中就跟手（读 mid 矩形）"与"竖条数为 0"，
  并反向钉"松手落点 = 预览位置、一步撤销回原位"。
