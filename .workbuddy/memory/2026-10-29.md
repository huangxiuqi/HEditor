## 清单收尾轮（N8 / N6 判据 / 总原则更正）

- **N8 光标变化判据**：`dom.ts` 拆成 `caretRelocated`（段、偏移、侧别、行别、页）与
  `caretMoved`（再加相位）。发 `caret` 事件用后者（相位翻转也要通知），滚视口用前者
  （相位翻转不该拽视口）。比较对象两份：`finish` 用 `lastCaretState`、`afterEdit` 用
  `lastState`，不是同一拍。
- **`setCaret(pos, opts)` 的 `line` 只在同时给了 `side` 时才下发**，无侧别分支是 plain 落点，
  不看行别。判据传 `{side, line}` 才能拿到软换行处的两个插入点。
- **软换行处两个插入点：`caretLineAff` 在 0/1 之间变，而 `caret().rect.y` 完全不变** ——
  「身份变了、几何没变」，正好是 N8 要钉的那一格。
- **N6 的 DPR=2 覆盖物判据**：IME 框 left/top 与拖格线时引导线 left，验
  「磅 × 密度 / dpr」。反向臂：`pxToCss` 去掉除 dpr，三条断言全红。引导线 div 加了
  `data-role="grid-guide"`（库现造、无类名，判据只能靠标记找）。
- **判据侧的 `ZOOM()` 不能改成读 `diag.stats().density`**：那是 float32，末位差异会让压在
  字符边界上的采样点翻边，`edit-sweep` 的横扫判据稳定红一个点（x=170.9 命中(7,1)/实际(7,-1)）。
  `ZOOM()` 保持 double 式子（密度），另加 `CSSPT() = ZOOM()/dpr` 给鼠标与覆盖物用。
- 闸：浏览器 134/134（dev 与 dist 各一遍）、`npm run check` 全 0、`format.ps1 -Check` 151。
  三条反向臂实测会红。清单只剩 N2（等 T8）。
