# 阶段 5 剩余任务

## 说明

阶段 5 的目标见 `docs/重构方案-纯管线-2026-10-27.md` 第八节：门面拆分、服务所有权、只读快照、宿主契约与 IDL 生成链。

当前按“兼容口径”完成了第一层：五个服务对象已经存在并持有各自的数据，宿主命令表已有单一 IDL 与跨端名字核对。以下清单记录离第八节完整目标还差什么，避免把“兼容口径收口”误读成 8.1–8.6 全部完成。

## 已完成

- `DocumentSession`：持有文档与撤销/重做历史；选区快照历史在 `doc::Session`。
- `ProjectionService`：持有块流、块尺寸/流位置、来源身份、表格、槽位与结构索引。
- `LayoutService`：持有 `LayoutResult` 与 `ShapingCache`。
- `RenderService`：持有 `PageCache`，并转发 `buildScene`。
- `EditSession`：持有 `CaretResolver`、`EditCommand` 与光标可见性。
- 单一 IDL：`web/src/engine/api.ts` 的 `IDL`。
- 跨端核对：`scripts/idl_check.mjs`，核对命令名、wasm 导出与不经过命令表的清单。

## 剩余任务

| 任务 | 当前状态 | 完成判据 |
| --- | --- | --- |
| 把投影重建搬进 `ProjectionService` | 服务只持数据，重建仍在 `EditorEngine::rebuildProjection` | 服务接口完成投影、损伤与控件跨度导出；引擎只转发 |
| 把排版编排搬进 `LayoutService` | 服务只持 `LayoutResult` / `ShapingCache`，全量、增量、后缀复用仍由引擎调用排版函数 | 服务拥有排版入口与 `LayoutSnapshot`；引擎不直接调 `layoutDocumentRange*` |
| 把瞬态层与光栅入口搬进 `RenderService` | `RenderService` 只有 `PageCache` 与 `buildScene`；Overlay 与光栅入口仍在引擎 | 服务拥有 Overlay 组装与光栅入口，或文档明确写出保留在引擎的边界与理由 |
| 当前选区并进 `DocumentSession` | 选区快照历史在 `doc::Session`，当前光标/选区仍在 `CaretResolver` | 文档、当前选区、视图、历史只有一个所有者 |
| 拆出独立 `EditorFacade` | 仍是巨大的 `EditorEngine`，生命周期、配置、编辑、呈现、诊断混在一起 | 门面只做转发与生命周期，约 30 个公开方法；实现落在服务 |
| 引入只读快照 | 服务成员可变，读路径直接读当前状态 | 使用 `shared_ptr<const Projection>` / `shared_ptr<const LayoutSnapshot>`，不再依赖成员地址稳定 |
| 落地 `apply` / `query` / `event` | 宿主逐命令调用，没有批量事务回执、版本化查询与统一事件 | `apply(commands[])` 返回 `Receipt{status, version, changed, rejections[]}`；`query(version)` 返回旧快照；事件带 `{version, invalidate, patch}` |
| IDL 生成 C++/TS/命令表 | IDL 只有命令表与核对；C++ 导出、TS 类型、参数校验仍手写；`payload_schema.gen.h` 由 C++ 侧 JSON 生成 | C++ 绑定、TS 类型、命令表、参数校验从同一份 schema 生成；删一条 IDL 命令，生成代码与判据必须红 |
| 阶段 5 判据 | 现有浏览器用例只覆盖行为，没有契约与快照判据 | 增加 `apply` 事务、`query(version)` 旧快照、拒绝/失败/无变化回执、服务边界与快照隔离判据 |

## 建议顺序

1. 服务所有权收口：投影重建、排版编排、渲染入口。
2. 选区与快照：当前选区单一所有者，只读 `Projection` / `LayoutSnapshot`。
3. 门面拆分：`EditorFacade` 只转发。
4. 宿主契约：`apply` / `query` / `event` 与版本化快照。
5. IDL 生成链：schema 生成 C++ 绑定、TS 类型、命令表、参数校验。
6. 补阶段 5 判据并更新验证记录。

## 结论

阶段 5 不是“已完成、只剩收尾”；它是“兼容口径已完成，完整门面与宿主契约未完成”。后续按上表推进，不用“兼容口径”代替 8.5 的判据。
